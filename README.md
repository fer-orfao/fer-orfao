🌿 PlantCare AI
🚀 Sobre el Proyecto
**PlantCare AI** es una aplicación web intuitiva desarrollada como MVP (Producto Mínimo Viable) para ayudar a los amantes de las plantas a gestionar los ciclos de riego, realizar un seguimiento de su colección y obtener diagnósticos rápidos de salud vegetal con la ayuda de la inteligencia artificial.
